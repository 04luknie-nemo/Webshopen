# Webbshop med React & Typescript

Mattias, Christian och Lukas gör tillsammans en webshopp som lämnas in som ett skolprojekt

# Desing systemet MUI: 
https://mui.com/material-ui/getting-started/ 

## Starta Projektet

/webshopen/api kör man: 
    - npm i
    - npm run db:generate
    - npm run db:push
    - npm run seed
    - npm run db:studio (Om man vill)
    - npm run dev

/webshopen/web kör man: 
    - npm i
    - npm run dev
